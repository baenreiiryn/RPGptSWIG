# Integração Cyberpunk — reconstrução

Base: RPGptSWIG main b26785b. Modos: Daggerheart, Cyberpunk RED 2045 e Cyberpunk Edgerunners 2077.

Esta reconstrução usa o arquivo original edgerunners-mission-kit-v11FVTT.zip e o atlas visual já gerado, sem novas gerações de imagem. Cada etapa é preservada em Git antes de continuar.

O estado Cyberpunk será separado de Daggerheart: PV restantes, dez atributos, perícias, Humanidade, papel, inventário, ações NET/físicas, rolagens e memória geográfica.

Os registros do mundo Foundry original pertencem a uma ambientação de 2055. As fichas importadas são referências que precisam ser contextualizadas pelo Mestre para 2045/2077. Macros, contas, logs de conversa e jornais privados não são importados.
